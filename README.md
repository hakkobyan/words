# words

Мобильное приложение для изучения английских и немецких слов с переводом на русский. Все слова, категории, сеансы, прогресс и настройки хранятся локально в браузере — сервер и регистрация не нужны.

## Возможности

- Английский и немецкий словари разделены; встроено по 500 офлайн-записей для автодополнения.
- Свои слова, категории и тематические сеансы.
- Поиск, фильтры, избранное, произношение через Speech Synthesis.
- Флеш-карточки, квиз и локальное интервальное повторение.
- Светлая/тёмная тема, импорт и экспорт JSON, демонстрационный набор.
- PWA-манифест и офлайн-кэш для установки на телефон.

## Запуск

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
npm run start
```

## Данные

Версионированные ключи `language_app_*_v1` хранят слова, категории, сеансы, настройки и метаданные. Слой `src/lib/storage.ts` безопасно разбирает JSON и не обращается к браузерному API во время серверного рендеринга. Резервная копия содержит версию схемы, дату экспорта и все пользовательские сущности.

Словарные записи находятся в `src/data/defaults.ts` и соответствуют типу `DictionaryEntry`. Для расширения добавьте базовую пару слова и русского перевода в массив нужного языка либо вынесите дополнительные записи в отдельный модуль.

## Развёртывание

Импортируйте репозиторий в Vercel; стандартные настройки Next.js подходят без изменений. Приложение не требует переменных окружения или внешней базы данных. После первого успешного посещения статические маршруты доступны из офлайн-кэша.
