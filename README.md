# words

Приложение для изучения английских и немецких слов с переводом на русский. Написано на Expo (React Native) — работает на iOS, Android и в вебе из одной кодовой базы. Слова, категории, сеансы, прогресс и настройки хранятся локально на устройстве, регистрация не нужна.

## Структура

```
mobile/   Expo-приложение (iOS, Android, веб)
api/      Serverless-функции Vercel: перевод и разбор субтитров YouTube
```

Функции в `api/` — это бэкенд приложения. Они нужны потому, что их работа невозможна на устройстве: перевод требует ключа DeepL, который нельзя класть в клиент, а разбор субтитров ходит к внутреннему API YouTube.

## Возможности

- Онбординг: тест на 20 слов уровней A1–C2 или выбор уровня вручную.
- Разминка при каждом запуске: 10 новых слов своего уровня и выше, перевод в обе стороны, добавление незнакомых слов в словарь.
- Свои слова, категории и тематические сеансы, поиск, фильтры, избранное, произношение.
- Флеш-карточки, квиз и локальное интервальное повторение.
- YouTube Vocabulary: словарь по субтитрам любого видео.
- Светлая/тёмная тема, импорт и экспорт JSON.

## Разработка

Приложение:

```bash
cd mobile
npm install --legacy-peer-deps
npm start
```

Откройте проект в Expo Go по QR-коду из терминала (`w` — веб, `a` — Android, `i` — iOS).

Проверка типов бэкенда:

```bash
npm run typecheck
```

## Развёртывание

Vercel собирает веб-версию Expo (`mobile/dist`) как статику и разворачивает `api/` как функции — см. `vercel.json`.

Переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `DEEPL_API_KEY` | Ключ DeepL. Без него перевод отвечает 503. |
| `DEEPL_API_URL` | Необязательно. По умолчанию выбирается по типу ключа. |
| `YOUTUBE_PROXY_URL` | Необязательно. Прокси для запросов субтитров. |

Мобильное приложение обращается к этому же развёртыванию: адрес задан в `mobile/src/lib/api.ts` и переопределяется через `EXPO_PUBLIC_API_BASE_URL` в `mobile/.env`.

## Данные

Ключи `language_app_*_v1` хранят слова, категории, сеансы, настройки и список показанных в разминке слов. Резервная копия содержит версию схемы, дату экспорта и все пользовательские сущности.

Банк слов для разминки — `mobile/src/data/wordBank.ts`, по 15 записей на каждый уровень CEFR для каждого языка.
